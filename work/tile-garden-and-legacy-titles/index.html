Game engineering

Tile Garden and legacy titles

Support, event UI and consent work on Tile Garden, plus two older coin-pusher games I revived with engine and Android API upgrades.

Context

Tile Garden (Lion Studios) is a garden-themed tile puzzle game with 1M+ downloads. The legacy titles are two older coin-pusher games.

My role

I was a developer on the Unity game client, adding support, seasonal event UI and the Lion SDK to Tile Garden, and reviving the two legacy games.

What I built

  • I added Helpshift support to Tile Garden.
  • I built seasonal event UI and integrated the Lion SDK.
  • I migrated the game to Google UMP and iOS ATT for consent and tracking permission.
  • I revived two older coin-pusher games with Unity and Android API upgrades, rebuilt their ad mediation and fixed their IAP.
