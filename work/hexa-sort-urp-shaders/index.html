Tech art

Custom URP shaders for Hexa Sort

Mobile cel-shading and a shadow-receiving transparent ground that I wrote in HLSL for Hexa Sort's board, replacing the third-party shaders.

Context

Hexa Sort is a hexagon-stacking puzzle game for Android and iOS, built in Unity with the Universal Render Pipeline (URP). Its board had been drawn with third-party shaders.

My role

I wrote the board's custom URP shaders in HLSL, as a developer on the Unity game client.

What I built

  • I wrote custom URP shaders in HLSL for mobile: cel shading, and a transparent ground that receives shadows.
  • The shaders are SRP Batcher compatible.
  • They replaced the third-party shaders on Hexa Sort’s board.
  • I extended an SDF rounded-corner tile shader for a jigsaw game.
