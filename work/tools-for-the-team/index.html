Editor tools for the game team

A code generator for new tile mechanics, level-editor features and a batch screenshot uploader that I built to speed up the Hexa Sort team's work.

Context

My role

I built these tools as Unity Editor scripts in C#, as a developer on the game client.

What I built

  • I built a code generator that scaffolds a new tile mechanic: its scripts, prefabs and config.
  • I built level-editor features for the team’s level editor.
  • I built a batch screenshot uploader for the level library.
